Swagger tool

  • Jeg tilvalgte OpenAPI 3.0 - Men ingen browser starter op?
  • Hvem har spist min Swagger page?
Årsag

Microsoft må have raget uklar med "domaindrivendev" som udvikler Swagger.
Tidligere var teksten "Enable Swagger..." men er ændret til "Enable OpenAPI 3.0".
"Enable OpenAPI 3.0" betyder at der genereres en JSON file med API beskrivelse. Men det åbner ikke en browser. Swagger er det interface som på baggrund af OpenAPI JSON filen kan lave et UI.
Der mangler derfor den kode som skal bringe UI op.

Procedure
  • Åben din solution
  • Åben "Tools-->NuGet Package Manager-->Manage Nuget Packages for Solution...
  • Vælg "Browse" tab
  • Indstaller "Swashbuckle.AspNetCore"
  • Create en folder "Glue" i dit projekt/li>
  • Luk din solution
  • Download "SwaggerGlue.zip" SwaggerGlue.cs
  • Kopier "Glue" folderen i zip filen til din projekt folder. (Den folder hvor du finder .csproj filen)
  • Åben din solution
  • Højreklik dit projekt og vælg "Add-->Existing item
  • Naviger til "Glue" folderen og "SwaggerGlue.cs"
  • Adder denne fil (Der vil nu være en ny folder i dit projekt kaldet "Glue")
  • Ændrer indholdet i din "program.cs" fil til:
  • using SwaggerGlue;                                       // This line is new.

var builder = WebApplication.CreateBuilder(args);
Glue openAPI = new Glue();                               // This line is new.

// Add services to the container.

builder.Services.AddControllers();
// Learn more about configuring OpenAPI at https://aka.ms/aspnet/openapi
// builder.Services.AddOpenApi();                        // This line was outcommented
openAPI.ConfigureBuilderOpenAPI(builder);                // This line is new


var app = builder.Build();

// Configure the HTTP request pipeline.
//if (app.Environment.IsDevelopment())                   // This line was outcommented
//{                                                      // This line was outcommented
//    app.MapOpenApi();                                  // This line was outcommented
//}                                                      // This line was outcommented
openAPI.ConfigureAppOpenAPI(app);                        // This line is new

app.UseAuthorization();

app.MapControllers();

app.Run();
